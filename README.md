# WatchSync V1.0.0

Premium private watch-party platform.

## Run
```bash
npm install
node server.js
```

## Render
- Root Directory: empty
- Build: `npm install`
- Start: `node server.js`
- Env: `TMDB_API_KEY`, `TMDB_READ_TOKEN` (optional)

## V1.0.0
- Profile rings (Pink Heart Ring + floating heart PNG effect)
- Fonts, nameplates, banners, effects, status orbs (all functional)
- Persistent profile cosmetics (localStorage)
- Rooms, library, chat, host sync
